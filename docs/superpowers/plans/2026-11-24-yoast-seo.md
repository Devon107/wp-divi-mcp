# Yoast SEO Title and Description Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two MCP tools, `seo_get` and `seo_update`, that read and write the Yoast SEO meta title and meta description of any exposed post. They register only when Yoast is active.

**Architecture:** A thin adapter, `WPDM\Seo\Yoast`, is the only code that touches Yoast. It reads and writes meta through `WPSEO_Meta`, rebuilds the post's indexable right away, and reads effective values from `YoastSEO()->meta`. The tools live in `includes/Tools/Seo/` and register through `wpdm_registry`, like the Divi tools. The tests run against real Yoast 28.9, loaded only when `WPDM_TEST_YOAST=1`.

**Tech Stack:** PHP 7.4+, WordPress, Yoast SEO 28.9, PHPUnit via wp-env.

**Spec:** `docs/superpowers/specs/2026-11-24-yoast-seo-design.md`

## Global Constraints

- Tools register only when `defined( 'WPSEO_VERSION' ) && function_exists( 'YoastSEO' )`.
- The only meta written are Yoast's `title` and `metadesc` keys, through `WPSEO_Meta` (prefix `_yoast_wpseo_`).
- An empty string deletes the meta, so Yoast falls back to its template.
- Warnings are given for an effective title over 60 characters, and for an effective description over 155 or under 50 characters. They are warnings only: the change still saves. Lengths are measured with `mb_strlen`.
- `seo_update` is not read-only. `seo_get` is read-only.
- Do not change the server instructions (1498/1500 chars).
- PHP 7.4 compatible.

## Review Focus

- **A post type the plugin does not expose (revision, nav item):** `not_found`, same as `get_post`. Pinned in Task 2 (`test_seo_get_unexposed_type_not_found`).
- **A title with HTML or line breaks:** stored as plain text, with tags stripped and whitespace collapsed. Pinned in Task 2 (`test_seo_update_strips_html`).
- **Neither field passed:** `invalid_argument`, nothing written. Pinned in Task 2 (`test_seo_update_requires_a_field`).
- **The front end shows the new title in the same request** (the indexable was rebuilt, not deferred to shutdown). Pinned in Task 2 (`test_seo_update_effective_changes_immediately`).
- **A Yoast API failure during the refresh** (Yoast class missing or renamed in a future version): the write still succeeds and returns a warning, never a fatal. Pinned in Task 1 (`test_refresh_failure_is_reported_not_fatal`).

**Interfaces:**
- Produces (all `public static`, class `WPDM\Seo\Yoast`):
  - `active(): bool`
  - `version(): string`
  - `stored( int $post_id ): array{title:string, description:string}`. Unset meta gives `''`.
  - `write( int $post_id, ?string $title, ?string $description ): void`. A `null` field is left unchanged, and `''` deletes it.
  - `refresh( int $post_id ): bool`. Rebuilds the indexable via `YoastSEO()->classes->get( \Yoast\WP\SEO\Integrations\Watchers\Indexable_Post_Watcher::class )->build_indexable( $post_id )`, then clears `\Yoast\WP\SEO\Memoizers\Meta_Tags_Context_Memoizer` (`->clear()`). Returns false on any `\Throwable`.
  - `effective( int $post_id ): array{title:string, description:string}`. Comes from `YoastSEO()->meta->for_post( $post_id )`. `''` when Yoast returns false or null, or on `\Throwable`.

**Interfaces:**
- Consumes: `WPDM\Seo\Yoast::*` from Task 1. From `WPDM\Tools\WordPress\PostSupport`: `bind_user`, `validate`, `find_post` (`find_post` throws `not_found` for unexposed types).
- Produces:
  - `seo_get` with input `{id: integer >= 1}`. Read-only, capability `edit_posts`. It returns `{id, title, description, effective_title, effective_description, yoast_version}`. Access follows `GetPost`: anyone who can `edit_post` it, or published, readable and not password-protected for others.
  - `seo_update` with input `{id: integer >= 1, title?: string, description?: string}`. Not read-only, capability `edit_posts`, and it needs `edit_post` on the post (else `forbidden`). It returns `{id, previous: {title, description}, title, description, effective_title, effective_description, warnings: string[]}`.
  - `Tools\Seo\Registrar::add( Registry $registry ): Registry` adds both tools only when `Yoast::active()`.
